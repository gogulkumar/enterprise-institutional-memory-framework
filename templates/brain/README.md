# Brain

Folders: `sources/`, `reasoning/` (business view, thinking patterns, judgments, response style), `knowledge/`, `dependency-map/`, `procedures/`, `tests/`, `logs/`, `proposals/`, `passes/`, `archive/`.

Never edit an entry by hand. Every change is a proposal applied by the applier (SPEC section 12.1). `index.yaml` is generated by `schemas/validate.py` (SPEC section 15.3).
