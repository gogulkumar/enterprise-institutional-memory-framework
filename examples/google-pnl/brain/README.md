# Brain

Folders: `sources/`, `reasoning/` (business view, thinking patterns, judgments, response style), `knowledge/`, `dependency-map/`, `procedures/`, `tests/`, `logs/`, `proposals/`, `passes/`, `archive/`.

Never edit an entry by hand. Every change is a proposal applied by the applier. `index.yaml` is generated by `schemas/validate.py`.
